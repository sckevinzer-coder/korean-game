# 한국어 학습 게임 (SRS 단어장) 설계

## 개요

초급 한국어 학습자를 위한 모바일 앱. Anki식 간격 반복(SRS) 단어 카드와 퀴즈로 어휘를 중심으로 학습하고, 문장 빈칸 문제를 통해 문법을 보조적으로 노출한다. UI 언어는 일본어.

## 목표 / 성공 기준

- 하루 10~20개 단어를 무리 없이 복습할 수 있다
- 복습 주기가 학습 결과에 따라 자동 조정된다
- TOPIK 급수별 단어장으로 수준에 맞게 시작할 수 있다

## 타겟 사용자

- 한국어 초급 (한글은 읽을 수 있는 수준)
- 모국어 일본어

## MVP 기능

1. **단어 카드** — 앞면: 한국어 + 발음(읽기), 뒷면: 일본어 뜻 + 예문 1개
2. **4지선다 퀴즈** — 두 가지 형식: 뜻 맞히기 / 단어 맞히기
3. **SRS 복습** — 다시/어려움/보통/쉬움 4단계로 다음 복습 시점 결정
4. **단어장** — TOPIK 급수별 (1급부터 제공)
5. **진척 표시** — 오늘 복습할 카드 수, 연속 학습일

## MVP 제외 (후속)

- TTS 한국어 음성 재생
- 사용자 단어장 편집/추가
- 서버 동기화 / 계정

## 기술 스택

- Flutter (iOS/Android 단일 코드베이스)
- 로컬 저장소: SQLite 또는 Hive — 단어 데이터와 학습 진척 저장, 서버 없음
- 단어 데이터: 번들된 JSON (단어, 읽기, 일본어 뜻, 예문, TOPIK 급수)
- 상태 관리: Riverpod

## 화면 흐름

홈(오늘 복습할 카드 수) → 카드 학습(앞/뒤 뒤집기, 난이도 선택) → 퀴즈(4지선다) → 결과(정답률, 연속일)

## 데이터 모델

- `Word`: id, korean, reading, meaning_ja, example_ko, example_ja, topik_level
- `CardProgress`: word_id, ease/interval/due_date, lapses, last_reviewed_at
- `UserStats`: streak, total_reviewed, last_study_date

## 검증

- SRS 주기 계산 로직 단위 테스트
- 카드 학습/퀴즈 세션 흐름 위젯 테스트
- 수동 스모크 테스트: 하루 학습 한 사이클 완주
